# Security Policy

## Supported Versions

| Version | Supported |
|---|---|
| 3.x | ✅ |
| < 3.0 | Not supported |

## Reporting a Vulnerability

We take the security of this module and its users seriously. If you discover a security vulnerability, please **do not** open a public issue.

Instead, send a detailed report to **<support@basantmandal.in>**.

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- Affected Magento version(s), PHP version(s), and module version.
- Any proof-of-concept code if available.

### What to expect

- **Acknowledgement** within 48 hours of your report.
- **Status update** within 5 business days.
- A fix will be developed, tested, and released as a patch version once confirmed.

We follow responsible disclosure: please allow us reasonable time to address the issue before any public disclosure.

## Scope

This policy applies to all code in the `hktech/csp-whitelisting` package, including its dependencies, build tooling, and documentation.
