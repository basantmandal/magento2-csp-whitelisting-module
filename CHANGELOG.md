# Changelog

All notable changes to this module are documented in this file.  
The format follows Magento Marketplace and semantic versioning guidelines.

---

## [2.1.0] - 2026-01-26

### Added

- Admin interface for adding/removing CSP URLs.
- Default CSP URLs for `script-src`, `style-src`, `img-src`, `connect-src`, `font-src`, `frame-src`, etc.
- Reset button to restore default CSP values.
- Fully compatible with Magento 2.4.0+.

---

## [1.0.3] - 2024-12-25

### Updated

- Updated CSP Whitelists: Added NitroPack/NitroCDN, jsdelivr.net, Tailwind CSS CDN, and other entries.

---

## [1.0.2] - 2023-07-15

### Updated

- Updated CSP Whitelists: Added ContentSquare URLs.

---

## [1.0.0] - 2022-06-14

### Added

- Initial release of **HK2 CSP Whitelisting** module.
